# ربات فروش پنل پاسارگارد

## نصب و اجرا
```bash
pip install -r requirements.txt
cp .env.example .env     # BOT_TOKEN و ADMIN_IDS را پر کنید
python3 bot.py
```
بعد از اجرا در ربات `/start` بزنید و از دکمه «⚙️ تنظیمات» همه‌چیز را تنظیم کنید:
۱) 🔌 پنل ← آدرس، یوزرنیم، رمز، «تست اتصال»  ۲) 💳 پرداخت ← شماره کارت  ۳) 📦 محصولات ← افزودن پلن.

## امکانات
- اتصال خودکار به پنل پاسارگارد و ساخت کانفیگ (با لینک ساب) برای هر خرید
- کانفیگ تست (یک‌بار برای هر کاربر؛ حجم و مدت از تنظیمات)
- نمایندگی: کاربر نمایندگی را می‌خرد و از آن به بعد قیمت نمایندگی هر پلن را می‌بیند
- پرداخت کارت‌به‌کارت با **تحویل فوری**: کاربر رسید می‌فرستد، سرویس همان لحظه ساخته می‌شود؛
  بعداً ادمین از پیام سفارش «✅ تایید نهایی» یا «❌ رد و حذف همه‌چیز» می‌زند.
  رد کردن، سرویس ساخته‌شده با آن پرداخت را از پنل پاسارگارد و ربات حذف می‌کند (و اگر نمایندگی بوده، نمایندگی لغو می‌شود).
  تحویل فوری را از تنظیمات ← پرداخت می‌توان خاموش کرد تا هر سفارش اول تایید شود.
- همه دکمه‌ها شیشه‌ای (inline) و پیام‌ها در جا ویرایش می‌شوند
- آدرس/یوزرنیم/رمز پنل، متن‌ها و نام دکمه‌ها، کارت، محصولات، تست و نمایندگی همه از داخل ربات قابل تغییرند

## نکات
- دیتابیس: فایل `bot.db` (SQLite)؛ از آن بکاپ بگیرید.
- گروه‌ها: پیش‌فرض کاربر به همه گروه‌های پنل اضافه می‌شود؛ برای محدود کردن، در تنظیمات ← پنل شناسه گروه‌ها را بدهید.
- پیام رمز پنل بعد از ذخیره از چت پاک می‌شود.
- برای اجرای دائمی از systemd یا `screen`/`tmux` استفاده کنید.
